# Rejected ideas

Ideas that were weighed and deliberately **not** adopted, written at the moment
of rejection — the only time the reasoning is cheap to capture. An idea that
leaves no trace comes back in full, and a rejection recorded without its reason
hardens into a permanent no.

Every file here carries the circumstance that would change the answer.

One file per idea: `<kebab-case-name>.md`, with the sections below.
